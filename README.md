# Autoescuela Micer Mascó — Sitio Web Oficial

Sitio web estático de alta conversión para **Autoescuela Micer Mascó** (Centro Homologado DGT `V 0968`), ubicada en Carrer de Misser Mascó, 10, 46010 Valencia (El Pla del Real / Mestalla).

## Estructura del Proyecto

- `index.html`: Landing page editorial en HTML5, CSS3 y Vanilla JS con sistema de triaje inteligente en popup hacia WhatsApp.
- `assets/`: Recursos visuales oficiales (logotipo, fachada desktop/mobile, vehículo de prácticas y galería de alumnos aprobados).
- `vercel.json`: Cabeceras de seguridad HTTP y política de caché para activos estáticos.

## Despliegue

Proyecto preparado para despliegue estático inmediato en **Vercel** o **GitHub Pages**.
